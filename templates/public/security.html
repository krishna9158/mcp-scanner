Authentication & Sessions

PBKDF2 600k + MFA

Passwords use PBKDF2-HMAC-SHA256 at 600,000 iterations. Persistent sessions and single-use reset tokens store only SHA-256 hashes, with TOTP MFA and login rate limiting.

Authorisation & Isolation

Strict Tenant RBAC

Every tenant API validates session ownership against the caller's organisation ID, enforces Admin/Member/Viewer roles, blocks cross-origin CSRF writes, and guards platform admin consoles.

Website & Upload Security

SSRF & Magic-Byte Guards

Public URL inspections block loopback, RFC1918, CGNAT 100.64.0.0/10, IPv4-mapped IPv6, metadata IPs, and unsafe redirects. File uploads allowlist safe extensions under 5 MB with magic-byte checks and X-Content-Type-Options: nosniff.

Infrastructure & Storage

Hosting & Encryption

Hosted on Render compute and persistent storage with optional Fernet file encryption at rest when configured, atomic file writes, and SHA-256 verified backup snapshots.

AI Data Disclosures

Local Grounded Engine

Default AI guidance runs locally on TrustAudit's DPDP statutory corpus. If an external LLM key is ever enabled by operator configuration, direct PII emails/phones/tax IDs are scrubbed before prompt construction.

Retention & Deletion

Data Minimisation & Account Purge

Zero Raw Patient Data Collection: TrustAudit manages categories and workflow metadata without requesting patient medical histories. Administrators can trigger complete deletion via /api/account/delete. Privacy contact: grievance@trustaudit.io | Security: security@trustaudit.io.
